# J.D. Gaskins Construction, Inc.

The website for J.D. Gaskins Construction, Inc., Aiken, SC. Built with [Astro](https://astro.build) (static output) by Still Waters Web Design, hosted on Netlify.

**Keep this repository private.** It contains the site's design code, which is licensed for this client's site only.
(Generated by `npm run contracting -- launch` in the swwd-site-builder repo; see `docs/contractor-site-launch-playbook.md` there.)

## Run it

```
npm install
npm run dev       # http://localhost:4321
npm run build     # builds to dist/
npm test          # the form-email function, photo picks, and review quotes
```

## Where things are

| What | Where |
|---|---|
| Everything about the business: name, phone, address, wording, reviews, sectors | `client/brand.mjs` |
| The site's photos (optimized WebP) | `client/web/<folder>/<number>.webp`, referenced in `brand.mjs` as `['residential-work', 1]` |
| The logo mark the favicon is made from | `client/logo-source/mark.png` (without it the favicon is the company's initials) |
| The design (the "General" look) | `src/looks/general/` |
| `<head>`: title, description, canonical, social previews, structured data | `src/shared/BaseHead.astro` |
| The live address of the site | `SITE_URL` in `astro.config.mjs` |
| Favicon and app icons | `public/` (regenerate with `npm run icons`) |

To change wording or the phone number or address, edit `client/brand.mjs` and push; Netlify rebuilds the site.

## Contact form

The form on the Contact page is a [Netlify Form](https://docs.netlify.com/forms/setup/) named `contact`. Every submission is stored in Netlify (Forms > contact); a honeypot field and Netlify's spam filtering keep bots out. After a submission the visitor lands on `/thanks/`.

**How the business gets the email.** Netlify's free plan only allows notification emails to members of the Netlify team, so the business is emailed by a Netlify function: `netlify/functions/submission-created.mjs` runs after each accepted submission and sends it through [Resend](https://resend.com) to `construct@jdgaskins.com`, from `forms@mail.stillwaterswebdesign.com`, with Reply-To set to the visitor.

Netlify environment variables: `RESEND_API_KEY` (a sending-only Resend key) and, for testing only, `FORM_TO_EMAIL` (every form email goes there instead; **delete it to go live**). Form detection must be ON for the site (the Netlify API: `processing_settings.ignore_html_forms = false`). Deploy the site together with the function: `netlify deploy --prod --dir dist --functions netlify/functions`. The free Netlify plan includes 100 form submissions per month. Glance at **Forms > contact > Spam submissions** now and then.

## The live address

The site is served at **https://jdgaskinsconstruction.com**. The address is set once, as `SITE_URL` in `astro.config.mjs`; canonical links, the sitemap, robots.txt, social previews and the structured data all read it. `public/_redirects` sends the default `jd-gaskins-construction.netlify.app` address to it.

## What Google sees

Every page has its own title, description, canonical and social tags; `/sitemap.xml` and `/robots.txt`; the thank-you and 404 pages are `noindex`. Structured data (JSON-LD) holds only facts in `client/brand.mjs`: no hours, prices, ratings or review markup unless the business supplied them. Audit it any time: `npm run contracting -- audit https://jdgaskinsconstruction.com` in swwd-site-builder.
